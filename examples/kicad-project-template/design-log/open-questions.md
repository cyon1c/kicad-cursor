# Open questions (single list)

The **consultant** queues items; any role may close one by answering it and logging the answer in `decisions.md`.

Do not hand-edit `design-context/open-questions.md` — that file is generated by `dump-design-context`. Promote generated items here when they need a human decision.

| State | Meaning |
|-------|---------|
| `open` | Blocks or risks a design choice |
| `deferred` | Acknowledged, intentionally not answered yet (note why) |
| `closed` | Answered — link the `decisions.md` entry |

## Template

```markdown
- [ ] **<id>** — <question> (state: open, owner: user | agent, blocks: <block/gate>)
```
